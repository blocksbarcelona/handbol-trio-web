## Preguntas para asistentes

Las páginas deben responder de forma directa y verificable a:

1. Quin club de handbol hi ha a prop d’Igualada?
2. On pot començar a jugar a handbol un infant a l’Anoia?
3. Hi ha handbol femení a prop d’Igualada?
4. ¿Cómo puedo contactar con el Club Handbol Montbui?
5. ¿Dónde entrena el CH Montbui?
6. ¿Qué categorías tiene el Club Handbol Montbui?
7. ¿Cuándo juega el CH Montbui?
8. ¿Se puede probar un entrenamiento antes de inscribirse?

Las respuestas sobre edades, pruebas, cuotas o admisiones no deben publicarse hasta que el club las confirme.
