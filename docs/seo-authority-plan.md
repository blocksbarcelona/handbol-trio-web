# Plan de autoridad local legítima

Solo se solicitarán menciones cuando exista una relación, actividad o información real. No se comprarán enlaces ni se harán intercambios masivos.

| Entidad u oportunidad | Motivo legítimo | Destino recomendado | Acción concreta | Prioridad |
|---|---|---|---|---|
| Ajuntament de Santa Margarida de Montbui | El club ya dispone de ficha municipal | `/club/` o `/contacte/` | Corregir NAP, descripción y añadir enlace canónico | P0 |
| Federació Catalana d’Handbol | Participación federada y fuente del calendario | `/calendari/` | Confirmar ficha del club y solicitar enlace oficial | P0 |
| Consell Esportiu de l’Anoia | Actividad deportiva comarcal y deporte base | `/club/` | Comprobar directorio y presentar información verificable | P1 |
| Instalación deportiva municipal | Lugar de entrenamiento y partidos | `/contacte/` | Confirmar denominación oficial y enlazar información de acceso | P1 |
| Centros educativos colaboradores | Actividades reales con alumnado | Página de la actividad | Facilitar una noticia útil con enlace, solo si existe colaboración | P1 |
| AnoiaDiari | Noticias deportivas y comunitarias | Crónica o actividad concreta | Enviar nota informativa con fuentes, fecha y fotografías autorizadas | P1 |
| InfoAnoia | Cobertura comarcal | Jornada abierta, torneo o noticia | Proponer información noticiable, no una petición genérica de enlace | P1 |
| La Veu de l’Anoia | Audiencia local y comarcal | Noticia o página del club | Ofrecer portavoz y datos verificables para una pieza real | P1 |
| Patrocinadores actuales | Relación económica o comunitaria real | Página de patrocinio | Pedir que identifiquen y enlacen la colaboración desde su web | P2 |
| Otros clubes y torneos | Rivales, organizadores o participantes reales | Página del evento o crónica | Enlazar recíprocamente información del evento, sin intercambio sistemático | P2 |
| Asociaciones locales | Actividades comunitarias compartidas | Página de actividad | Crear una página conjunta solo si la actividad se realiza | P2 |
| Instagram y YouTube oficiales | Confirmación de entidad y navegación | `/` o página relevante | Unificar nombre, ubicación y dominio en las biografías | P1 |

## Registro mínimo

Por cada gestión anotar fecha, persona responsable, URL de origen, URL de destino, estado, dato corregido y fecha de próxima revisión.
